# HD Direkt Gmail signature assets

Public HTTPS image assets used by the HD Direkt company Gmail signature generator.

- `logo-animated.gif` – animated HD Direkt logo
- `divider.gif` – animated divider
- `icon-fb.png` – Facebook icon
- `icon-ig.png` – Instagram icon
- `icon-li.png` – LinkedIn icon

These files are intentionally public because email clients must be able to fetch them without authentication.
